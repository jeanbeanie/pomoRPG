# PomoRPG

## Have you done your part in the war against procrastination?

PomoRPG is a simple pomodoro tool inspired by Role Playing Games (RPGs). 
Set a timer dedicated to completing the project of your choosing without distraction. Staying focused
rewards you with experience points (XP) which can be used to level up skill trees.

## Features to be added

- Track streaks to help build consistency
